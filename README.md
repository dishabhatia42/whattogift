# What to Gift

Pick the occasion, add what they love, get gift ideas you can actually buy.

- `/` – the gift finder (AI ideas + Disha's picks + sponsored slots)
- `/manage` – private admin, locked by `ADMIN_PASSWORD`

## Setup on Vercel
1. Storage → create a **Blob** store (Public access) and connect it to this project.
2. Environment variables: `ANTHROPIC_API_KEY`, `ADMIN_PASSWORD` (12+ characters).
